# Dongdong 🐈

给两个人用的像素小猫桌宠，支持 Windows 和 macOS。

- 一对一连接，两边同步摸摸、招手、投喂、抱抱等互动。
- 小猫可以拖动，也能在屏幕上散步、蹦跶。
- 直接在小猫旁发消息，收到消息时弹出气泡提醒。
- 拖入文件即可发送，对方自动接收至下载文件夹，记录中可查看进度。
- 支持开机自启动，可选择闲置时靠在屏幕侧边。
- 常驻 macOS 菜单栏或 Windows 系统托盘；桌宠、设置和消息窗口均不占用 Dock／任务栏。
- 尚未连接房间时，菜单栏／托盘的「消息」入口不可用；连接后自动启用。

点击 macOS 菜单栏的小猫，或右键点击 Windows 系统托盘图标，即可显示／隐藏咚咚、打开消息或设置，以及退出应用。Windows 下左键点击托盘图标也可唤回咚咚。关闭桌宠只会隐藏它，应用继续在后台运行；需要完全关闭时请选择菜单中的「退出」，也可右键点击桌宠后选择「退出」。
